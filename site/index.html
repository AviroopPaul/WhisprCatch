FAQ

Questions

The short version: WhisprCatch is the open-source Wispr Flow alternative for Linux — same hold-to-talk dictation, none of the cloud.

Is there an open-source Wispr Flow alternative?

Yes — that's exactly what WhisprCatch is. Wispr Flow (often searched as "Whisper Flow") is closed and subscription-based, and doesn't ship a Linux app at all; WhisprCatch gives you the same flow on macOS and Linux: hold a key, speak, release, and punctuated text is typed at your cursor in any app. Free and open source, with no account and no subscription.

Is it really free?

Completely. $0 forever, no account, no trial, no subscription. Every line is MIT-licensed on GitHub — read it, audit it, fork it.

Does my voice leave my laptop?

No. Speech-to-text runs on your CPU with zero network calls while you dictate — fully offline after a one-time model download. Your audio is decoded in memory and never uploaded.

Which platforms does it work on?

macOS 11+ on Apple Silicon via Homebrew, and Ubuntu or Debian (x86-64) via the .deb; anything else builds from source. It types into whatever has focus — editors, browsers, chat apps, terminals.

What do I need to do on macOS after installing?

macOS needs three permissions before WhisprCatch can hear the hotkey and type for you: Accessibility, Input Monitoring and Microphone. Open the app once and the first-run wizard walks you through each one. macOS only re-reads them when an app starts, so quit and reopen WhisprCatch afterwards — then hold Right ⌘ and talk. Run whisper-catch doctor any time to see which grants are live.
