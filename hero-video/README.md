# hero-video

HyperFrames source for the landing-page hero demo video (site/assets/hero-demo.mp4): an email written by holding fn on macOS, with the pill drawn to match the app (docs/DESIGN.md §B5).

```sh
npx hyperframes preview   # edit in Studio
npx hyperframes render --quality high --output ../site/assets/hero-demo.mp4
```
