# Embedded fonts

All three families are licensed under the SIL Open Font License 1.1, the text of
which is in `OFL.txt` alongside this file.

| Family | Files | Used for |
| --- | --- | --- |
| [Geist](https://github.com/vercel/geist-font) | `Geist-Regular/Medium/SemiBold.ttf` | UI text, labels, buttons |
| [Geist Mono](https://github.com/vercel/geist-font) | `GeistMono-Regular/Medium.ttf` | Timestamps, readouts, hotkey chips |
| [Newsreader](https://github.com/productiontype/Newsreader) | `Newsreader-Regular/Italic.ttf` | Display type: wizard titles, transcript body |

Newsreader is the same face the website sets its headlines in. See
`docs/DESIGN.md` §B1.
